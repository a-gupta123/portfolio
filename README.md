# Aryan Gupta — Personal Portfolio

Personal site for [Aryan Gupta](https://github.com/a-gupta123), a Mathematical Sciences + Computer Science student at Carnegie Mellon University.

**Live:** https://a-gupta123.github.io/portfolio/

## Stack

- Next.js 16 (App Router, static export)
- Tailwind CSS v4
- shadcn/ui
- Magic UI (Blur Fade, Marquee, Number Ticker, Border Beam, Particles, Text Animate)
- Aceternity UI (Spotlight)
- Motion
- GitHub Pages

## Color palette

[Coolors: `#03045E` `#0077B6` `#00B4D8` `#90E0EF` `#CAF0F8`](https://coolors.co/palette/03045e-0077b6-00b4d8-90e0ef-caf0f8)

## Local development

```bash
npm install
npm run dev
```

Content lives in `data/site.ts`. Replace `public/portrait.png` with a headshot if you want, and add a phone number in `site.phone`.
